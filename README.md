# Hello-world-or-die
This is a micro program I made when bored on 11.10.2026.

## What is it?

This program makes you type Hello World! but one typo closes the program.

## How to compile:

If you don't have g++ installed on Ubuntu/Debian systems you can install it from the terminal:
```
sudo apt update
sudo apt install g++
```
Compiling on Linux terminal:
```
cd /Path/To/Project
g++ "Helloworld.cpp" -o "Hello-world-or-die"
```
## Run:
```
./Hello-world-or-die
```
